# E-Commerce REST API Testing

## Project Overview
This is a beginner-level REST API testing project created using Postman and Fake Store API.

## Tools and Technologies
- Postman
- REST API
- JSON
- JavaScript
- Git and GitHub

## API Testing Methods
- GET – Retrieve product details
- POST – Create a product
- PUT – Update product details
- PATCH – Partially update product details
- DELETE – Delete a product

## Test Scenarios
- HTTP status code validation
- Response body validation
- JSON field validation
- Positive testing
- Negative testing
- Invalid endpoint testing
- Invalid product ID testing
- Environment variable testing
- Collection Runner execution

## API Used
https://fakestoreapi.com

- E-Commerce REST API Testing.postman_collection.json

## Note
This is a personal practice project using a demo API. Create, update and delete operations are simulated by the API.
